DataTable-AltEditor / Example 04

Additional field options

Edit an IPv4 address, an on/off selection, and a single port from 0 to 65535. Addresses must be unique. The hidden row identifier and read-only field are retained when editing. Refresh restores the original rows.

New rows default to off and port 8080. Edit a row to compare readonly and disabled fields in the submitted values.
